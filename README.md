# 番茄净化

[官网](https://fanqie.goforit.si/) · [插件源](https://apt.mjh.im) · [正式版 3.1.0](https://github.com/5hux1n/fanqiefn/releases/tag/v3.1.0)

iOS 越狱插件，为番茄小说（com.dragon.read）提供广告与界面净化、通知/小组件伪装、会员状态伪装，并在原生设置菜单加入“番茄净化”二级菜单入口。

## 原生设置开关

进入“我的 → 设置”，第一个分区中“清理缓存”上方的“番茄净化”进入二级设置页。入口、分区、菜单行和开关均复用番茄自身的 `SSSettingViewController`、`SSSettingTableViewCell` 和 `SSMaterialSwitch`，没有自绘单元格或滚动保存提示。

每次启动 App，隐藏类、优化类、增强类均从收起状态开始。未保存配置时，总开关默认开启，默认启动页跟随 App；各功能默认值以菜单说明为准，升级保留已有功能选择。

共 **插件总开关 + 37 个功能开关 + 默认启动页菜单 + 底部版本/反馈/插件源/咖啡链接分区**：

- 插件总开关：位于二级菜单第一行，默认开启；关闭后暂停所有功能及启动页覆盖，保留各分项选择和设置入口。

- 启动后自动领福利、福利任务静默执行：默认开启，位于“增强类”；关闭后立即回到原生行为。
- 原有九项净化/伪装功能。
- 章末作者的话、本章讨论、圈子按钮、送礼物、最新章节三个按钮：各自独立，首次默认关闭；开启后隐藏。
- 底部福利导航、我的页面福利卡片：默认关闭，开启后隐藏福利导航或整张金币/余额/提现卡片；保留下方圈子及其他模块。
- 我的页关注推荐卡片：独立隐藏开关，首次默认关闭，保留卡片。
- 返回按钮标题固定为当前章节名：默认关闭，开启后翻章跟随当前页面更新。
- 默认启动页：书城 / 短剧 / 书架 / 我的 / 跟随 App 设置，复用番茄的原生选择面板。默认跟随 App，不影响原设置；选择其他项后冷启动按所选页面进入。

会员到期仍为 9999-12-31，原有保存值保留。阅读右上角金币倒计时/“去赚更多”、阅读菜单听书悬浮按钮各有独立隐藏开关，默认关闭。书架底部推荐沿用 App 官方开关。增强类新增“双击切换自动阅读”，默认关闭；开启后正文双击开启或结束原生自动阅读，替代原生双击听书。开关保存在本机；切换后彻底结束并重新打开番茄，使已生成的页面和底部导航重新加载。催更、更新历史仍保留。

## 功能

- **通知权限伪装** — 拦截 iOS 通知授权请求，始终返回已授权，避免弹出系统通知权限对话框
- **通知设置伪装** — 将所有通知设置（提示、声音、角标、预览）伪装为已启用状态
- **远程推送伪装** — 返回已注册远程推送状态，拦截注册调用避免触发弹窗
- **小组件伪装** — 拦截 `NSUserDefaults` 中小组件相关 key 的读取，返回已添加状态
- **弹窗拦截** — 拦截包含小组件关键词的 `UIAlertController` 弹窗，彻底去除提醒

## 安装

### 系统要求

- iOS 15.0+
- Rootless（Dopamine / palera1n）或 RootHide 越狱环境
- 番茄小说已安装

### 方式一：下载预编译包

在 Sileo / Irisin 添加 `https://apt.mjh.im`，搜索“番茄净化”；或从 [官网](https://fanqie.goforit.si/#download) 选择适合的方案。

当前正式版本为 3.1.0，提供混淆安装包。

| 方案 | 安装包 | 安装布局 |
|---|---|---|
| Rootless | `fanqiefn_3.1.0_arm64.deb` | `/var/jb/Library/MobileSubstrate/DynamicLibraries` |
| RootHide | `fanqiefn_3.1.0_arm64e.deb` | `/Library/MobileSubstrate/DynamicLibraries` |

两种包均含 arm64 与 arm64e 切片；RootHide 原生构建，不能仅改 Rootless 包的 Architecture。本轮仅交付两个 DEB。

从 [Releases](https://github.com/5hux1n/fanqiefn/releases) 页面下载 `.deb` 文件，使用包管理器（Sileo / Irisin）安装，或通过命令行：

```bash
dpkg -i fanqiefn_*.deb
```
